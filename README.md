# SAPI — Sistema de Alerta Prévio de Inundações

**Flood Early Warning System** — a low-cost, open-source, LoRa-based platform for water-level
and rainfall monitoring, machine-learning flood forecasting and multi-channel alerts,
developed and validated as a Master's dissertation project (IFSC, Florianópolis, Brazil).
